# Shark Arena

Shark Arena is a responsive React, TypeScript, Tailwind, and shadcn/ui startup
pitch simulator. Founders pitch to four investor personas, answer their
questions, and receive an AI-generated assessment and hypothetical offer.

Gemini through the Google AI Studio Developer API generates the investor
questions and final assessment through TanStack Start server functions. The
`GOOGLE_API_KEY` is server-only. Pitches and answers are sent to Google for
processing; configure the key before using the AI flow. No login or database
is required.

The app has a local mock provider for automated tests, but the product flow uses
Gemini and does not silently fall back to rule-based scores if Gemini fails.

## Deploy to Vercel

Lovable continues to publish this project at the live app URL above. To deploy a
separate copy to Vercel:

1. Make sure the project is synced to its GitHub repository from Lovable.
2. In Vercel, import that repository. Set the project root to the directory
   containing this `package.json` if it is not at the repository root.
3. Keep Vercel's detected install command and use `npm run build` as the build
   command. Leave the output directory unset so Nitro can provide Vercel's
   deployment output.
4. Deploy. Vercel will give this deployment its own `*.vercel.app` URL; add a
   custom domain in Vercel if you want this copy to use your own domain.

The Vercel Nitro preset is selected for external builds. Lovable's own build
continues to use the deployment target selected by Lovable.

## Configure Google Gemini

The investor questions and final assessment are generated by the Gemini
Developer API (Google AI Studio) through server functions. This does not use the
Vertex AI API. The Google API key stays on the server; never expose it in a
`VITE_*` variable or commit it to Git.

1. Create a Gemini API key in [Google AI Studio](https://aistudio.google.com/apikey).
2. Keep the key private. Apply the Gemini API restriction if the key settings
   offer it.
3. Set `GOOGLE_API_KEY` to that key in the server environment:
   - Locally, create `.env.local` beside `package.json`, add
     `GOOGLE_API_KEY=your-key`, and run `npm run dev`.
   - On Vercel, add `GOOGLE_API_KEY` under **Project Settings → Environment
     Variables** for the environments where you deploy, then redeploy.
   - On Lovable, add `GOOGLE_API_KEY` as a server-side secret in the project
     settings if deploying the AI-enabled version there.

The app uses the `gemini-3.5-flash` model through the Gemini Developer API.
Pitch text and answers are sent to Google to generate questions and feedback.
Scores and hypothetical offers are AI-generated practice feedback, not
investment decisions or financial advice.
